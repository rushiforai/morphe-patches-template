# speedtest-morphe-patches

Morphe patch bundle for **Speedtest** (`org.zwanoo.android.speedtest`), target version `7.1.2`.

Generated by Morphe Pilot from `MorpheApp/morphe-patches-template`.

## Patches

| Patch | Default | What it does |
|-------|---------|--------------|
| Disable ads | on | Forces `com.ookla.speedtest.ads.b$d.a(I)Z` to return `true`, so every ad renderer (banner, native, DFP loader, internet-screen renderer) treats ads as disabled. |
| Disable Firebase analytics | on | Stubs all four public entry points of `com.ookla.tools.logging.android.FirebaseAnalyticsEventLogger` to `return-void`, so no events, user properties or counters reach Firebase. |

## Layout

- Patches: `patches/src/main/kotlin/dev/rushi/morphepatches/patches/speedtest/`
- Shared compatibility: `patches/src/main/kotlin/dev/rushi/morphepatches/patches/shared/Constants.kt`
- Extensions: `extensions/extension/` (unused — both patches are pure bytecode edits)

## Build

`./gradlew build` — needs JDK 21 and a GitHub token with `read:packages` in
`~/.gradle/gradle.properties` as `gpr.user` / `gpr.key`. See `BUILD.md`.
The bundle is written to `patches/build/libs/patches-1.0.0.mpp`.

No root is required at any step.
